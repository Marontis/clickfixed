Attack Anatomy

How a ClickFix Attack Actually Happens

Five steps, zero malicious links, and the victim does all the work.

1

Attacker Compromises a Real Website

Attackers don't build fake sites — they inject JavaScript into legitimate, trusted websites (often WordPress sites with outdated plugins). Your browser's URL bar shows a real domain you may recognise.

2

A Convincing Modal Appears

The injected script overlays a modal that looks exactly like a browser warning, a CAPTCHA, or a Windows system error. Common lures include:

"Verify you are human: Press ⊞ Win + R,
paste the code below, then press Enter."

"Your browser is missing a font. Run this fix."

"Microsoft Word encountered an error opening
this document. Click Fix to resolve."
3

One Click Copies the Payload

Clicking the button silently calls navigator.clipboard.writeText() — the Web Clipboard API. A long, obfuscated command is now in the user's clipboard, completely invisible to them.

powershell -w h -ep bypass -e JABzAD0ATgBlAHcALQBPAGIA
amBlAGMAdAAgAE4AZQB0AC4A
V2BlAGIAQwBsAGkAZQBuAHQA...
4

The User Pastes Into a Terminal

The user follows the instructions: presses Win + R to open the Run dialog, presses Ctrl + V to paste, and Enter to run. The malicious command executes with full user permissions.

5

Silent Infection — No Download Required

The payload downloads and runs a Remote Access Trojan, infostealer, or ransomware dropper — all through legitimate Windows utilities like PowerShell, mshta, or certutil. No file is "downloaded" in the traditional sense, so antivirus often doesn't trigger.

🛡️

Where ClickFixed Stops It

ClickFixed hooks the clipboard API at Step 3. The moment writeText() is called with a suspicious payload, the write is blocked before it completes — the user never even sees the malicious command in their clipboard.

The Gap

Why Traditional Defenses Miss This

Every conventional control is looking in the wrong place.

🔗

URL / Link Scanning

The attacked URL is a legitimate site. There's no malicious link to scan — the payload lives in JavaScript code injected into a real page.

📁

File Download Scanning

Nothing is downloaded to disk before execution. The command arrives via the clipboard and runs directly in PowerShell as a string.

🛑

Signature-Based AV

The payload is Base64-encoded and freshly obfuscated per victim. No static file hash or known pattern to match against.

📧

Email / Phishing Filters

There is no phishing email. Users land on the compromised site through organic search results, ads, or social media shares.

👁️

"Don't Click Links" Training

There's no link to not click. The training tells users to be suspicious of emails. This arrives as a browser pop-up on a real, recognisable site.

🔒

Browser Sandbox

The browser does exactly what the page requests — a clipboard write. The sandbox is working correctly. The problem is the content of the write.

Variants

ClickFix Has Many Faces

Attackers continuously evolve the lure. Same clipboard trick, different costume.

🤖

Fake CAPTCHA Verification

The most common variant. A convincing "I'm not a robot" modal instructs the user to press Win+R and paste a "verification code". Used heavily in 2024–25 by the ClearFake framework.

Most Common
🌐

Fake Browser Update

Mimics Chrome or Edge update dialogs. "Your browser is critically out of date. Run this update script." Often uses authentic browser logos and version numbers.

High Volume
💥

CrashFix (Browser Crash)

Forces a browser crash loop using JavaScript, then shows a recovery page instructing the user to "run the diagnostic script" to restore their session. Urgency manipulates users to act fast.

Emerging
📄

Fake Document Error

Appears when a Word/PDF document is shared. "Microsoft Word encountered an error. Use this PowerShell fix to repair it." Targets business users opening shared files.

Enterprise
📂

FileFix (File Explorer)

A newer variant targeting non-technical users: instructs them to paste the command into the Windows File Explorer address bar (Ctrl+L) instead of PowerShell — easier for novices to follow.

New 2025
🪟

Fake Windows Update

A full-screen overlay mimics the Windows 11 update screen ("Configuring Updates… 34%"). After a fake progress bar completes, users are asked to "apply a patch" via the Run dialog.

Real-World Impact

Notable Campaigns & Incidents

These aren't theoretical risks. ClickFix has been used by nation-state actors and criminal syndicates against real targets.

🇷🇺
Nation-State · APT28

Russia's Fancy Bear Adopts ClickFix

Late 2024 – 2025

APT28 (Fancy Bear), Russia's premier military intelligence cyber unit, incorporated ClickFix into its espionage operations to replace more complex infection stages. By shifting the execution burden to victims, they reduced technical footprint and bypassed enterprise EDR tools used by government and defence contractors.

Lure: Fake NATO briefing document viewer
Payload: Credential harvester + C2 beacon
📎 Microsoft Threat Intelligence
🇰🇵
Nation-State · Kimsuky

North Korea's Kimsuky Targets Nuclear Researchers

2024 – 2025

Kimsuky, a North Korean APT group, deployed ClickFix against think tanks, academic institutions, and nuclear policy researchers. Their custom forceCopy implant — delivered via ClickFix — extracted browser-stored credentials and copied sensitive documents to attacker-controlled servers.

Lure: Fake academic PDF reader / font fix
Payload: forceCopy credential stealer
📎 The Hacker News — Kimsuky
🦠
Malware-as-a-Service

Lumma Stealer: 394,000 Infections via ClickFix

March – May 2025

In a three-month window, Lumma Stealer (LummaC2) — sold as a subscription service on dark web forums — infected over 394,000 Windows computers primarily through ClickFix lures. It harvested saved browser passwords, session cookies, and cryptocurrency wallet seeds. Microsoft and international law enforcement seized thousands of its domains in May 2025.

Lure: Fake CAPTCHA on compromised sites
Payload: Password + cookie + crypto stealer
📎 Microsoft Security Blog
🌐
Criminal Campaign

ClearFake: 9,000+ Sites Compromised

2023 – Ongoing

ClearFake is the most widespread ClickFix distribution framework. Operated by a criminal group, it has compromised over 9,000 legitimate websites and serves tailored lures to millions of visitors. Each victim receives a freshly obfuscated command generated by the attacker's API, defeating signature-based detection.

Delivery: Injected JavaScript on real sites
Payloads: Vidar, DanaBot, NetSupport RAT
📎 Proofpoint Threat Insight
🏥
Healthcare Sector

HHS Warning: Hospitals Under ClickFix Attack

2024

The U.S. Department of Health and Human Services issued a specific advisory warning healthcare organisations that ClickFix campaigns were directly targeting hospital staff and clinical workers — specifically exploiting fake "medical record system" error messages to gain footholds on hospital networks.

Lure: Fake EHR / medical records system error
Goal: Ransomware pre-positioning
📎 HHS Cybersecurity Advisory

Government Advisory

CISA + FBI: ClickFix Used in Ransomware Pre-Positioning

2025

CISA and the FBI issued a joint advisory confirming that multiple ransomware groups are now using ClickFix as their primary initial access vector against critical infrastructure, replacing email phishing. The advisory noted that human-executed payloads are far harder to attribute and block retroactively.

Target: Critical infrastructure operators
Goal: Ransomware deployment + data exfil
